    Save layout

    The layout (the widgets, their settings and texts) is saved in this report's layout.js file. Replace it with the current layout:

    The file is layout.js, in the data folder next to the report's index.html.

    Option A: download

    1. If the browser asks where to save it, paste the copied path into the file name box.
    2. Otherwise, move layout.js from your Downloads folder into the report's data folder, replacing the old file.

    Option B: copy

    1. Open the report's data/layout.js in a text editor (e.g. Notepad).
    2. Select everything, paste, and save.

    Then reload this page to check the saved layout.
